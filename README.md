# Beauty Boost — Spring Boot

Migración del backend NetBeans a Spring Boot 3 / Java 17 / Maven. Configure `DB_URL`, `DB_USERNAME`, `DB_PASSWORD` y las variables `WOMPI_*`; no se incluyen credenciales. El SQL original compatible está en `src/main/resources/db` y el código/vistas NetBeans originales se preservan en `legacy-netbeans-source` y `src/main/resources/legacy-jsp` como referencia durante la migración de vistas JSP a Thymeleaf.
